# Changelog

## 1.0.0

- Synthetic transaction generator in the assignment schema (January-September 2026).
- Point-in-time feature engineering with 30-day lookbacks and a 7-day label delay.
- Logistic Regression baseline and gradient-boosting champion, time-based split,
  Platt calibration, three-band decision policy (approve / review / block).
- Input validation, drift statistics (PSI, KS) and monthly monitoring with an action runbook.
- FastAPI scoring service with structured logs, Prometheus metrics and a prediction log.
- Optional LLM-written explanations with a deterministic template fallback.
- Next.js analyst console.
